**PrepTrack** is a high-performance, offline-first preparation console and syllabus planner engineered specifically for **IIT JEE Main & JEE Advanced** aspirants.

---

## ⚡ Key Features

- ⏱️ **Interactive Study Timer & Stopwatch**: High-precision stopwatch and Pomodoro timer with auto-break notifications, ambient focus audio, and continuous local progress tracking.
- 🎯 **Chapter-Wise Syllabus Tracker**: Comprehensive class 11 and class 12 curriculum checklists for Physics, Chemistry, and Mathematics.
- 📕 **Smart JEE Error Book & Mistake Log**: Offline repository to categorize, tag, and review conceptual errors, calculation blunders, and question pitfalls.
- 📊 **Analytics & Solved Question Counters**: Visual historical graphs, daily practice tracking, and study hour distribution charts.
- 📝 **Mock Test Tracker**: Log, analyze, and diagnose JEE Main & Advanced full-length mock test scores with percentile and subject-wise breakdowns.
- 📌 **Scratchpad & Quick Notes**: Real-time debounced notes and task scratchpad with persistent auto-saving.
- 🎨 **Multiple Themes**: Modern glassmorphic, cyber, light, and dark palettes optimized for long focus sessions.

---

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/Soham-Mukherjee25/PrepTrack-JEE.git

# Navigate into the project folder
cd PrepTrack-JEE

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```

## 🛡️ Privacy & Performance

- **100% Client-Side / Local Storage**: All personal session logs, error records, and syllabus checkmarks are stored locally in IndexedDB / Web Storage.
- **Optimized Rendering**: Sub-components are code-split and memoized with debounced persistence to guarantee zero input lag.
